# DevOps Scripts Repository

Collection of bash scripts and automation tools for DevOps operations.

## Week 2 Scripts

### System Health Check
- **File:** `system_health.sh`
- **Purpose:** Monitor CPU, RAM, disk usage, hostname
- **Usage:** `bash system_health.sh`

### Service Status Check
- **File:** `check_services.sh`
- **Purpose:** Check if services (PostgreSQL, SSH, Docker) are running
- **Usage:** `bash check_services.sh`

### Port Checker
- **File:** `port_checker.sh`
- **Purpose:** Check if specific ports are open/listening
- **Usage:** `bash port_checker.sh`

### Deployment Script
- **File:** `deployment_script.sh`
- **Purpose:** Deployment with error handling and dependency checks
- **Usage:** `bash deployment_script.sh`

### File Operations
- **File:** `file_operations.sh`
- **Purpose:** Log file creation, appending, rotation with timestamps
- **Usage:** `bash file_operations.sh`

## Getting Started

```bash
git clone <repo-url>
cd devops-scripts
bash system_health.sh
```
